Date: 2026-08-06

  or when completeness cannot be established.

  plugin-owned drafts on failure.
- Keep inline async execution available when bundled queries have not been published; saved-query
  execution retains NQE diff support.
- Add source-absent wheel acceptance against both supported Nautobot release lines.
