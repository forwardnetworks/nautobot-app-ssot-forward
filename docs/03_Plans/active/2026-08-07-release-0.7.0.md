# Release 0.7.0

Date: 2026-08-07
Summary: native cloud ingestion with cloud-only account scope and async NQE diffs

## Changes

- Add explicit `network`, `cloud`, and `all` profile/job execution modes.
- Add generic cloud-type and account-ID allowlists with account-first child closure.
- Write accounts, networks, subnets, prefixes, and services to native Nautobot cloud models.
- Use saved-query NQE diffs as the cloud change detector and async full hydration when native
  DiffSync needs complete current state.
- Preserve inline async execution when bundled cloud queries have not been published.
- Replace name-only cloud identity with stable account-qualified identities while keeping display
  labels readable.
- Keep cloud reconciliation create/update-only until managed-object ownership supports safe
  deletion.
