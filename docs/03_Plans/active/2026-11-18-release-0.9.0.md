# Release 0.9.0

Date: 2026-11-18
Summary: Contrib-only writes, operator diagnostics (explained failures, pre-flight health, architecture audit, drift and figure index in the bundle), delete-override history, live-run fixes for cable sync and hand-made Nautobot objects; forward-sdk 0.1.38, Nautobot 3.1.8 and 3.2.9

## Changes

- Writes go only through nautobot-ssot contrib CRUD. The hand-rolled write executor, the
  `use_contrib_sync` toggle and the registry `write_handler` field are removed. This is a behavior
  change for anyone who relied on the old executor, so the release is a minor bump.
- Live-run fixes: cable sync no longer sends a parameters payload the query rejects (HTTP 400), and
  hand-made Nautobot objects with empty relations or no name no longer break a sync.
- Operator features: explained failures in `last_failure`, `forward_health`,
  `forward_architecture_audit`, drift explanations and a figure label index in the support bundle,
  and `ForwardDeleteOverride` (migration 0009) with `forward_delete_overrides`.
- The query publisher refuses to edit published queries while staged edit or delete drafts exist
  that it cannot attribute to a path.
- Release tooling: `scripts/release.py` now moves the README compatibility table's `Current` row
  with the version strings, and the release gate fails when that row disagrees with the package
  version. `check_wheel_contents.py` also requires `contrib_sync.py`, `managed.py` and the
  remaining migrations in the wheel.
- Platform: forward-sdk 0.1.38, Nautobot 3.1.8 and 3.2.9, nautobot-ssot 4.8.0, `cryptography` cap
  widened to `<51`. NQE executions retry on `SYSTEM_ERROR` through the SDK.

## Verification

- `python scripts/ci_local.py` exit 0 on the release tree: 10 of 10 steps, 306 tests passed,
  installed-wheel acceptance for plugin 0.9.0 on Nautobot 3.1.8 and 3.2.9.
- Container suites on both Nautobot lines, the three real-database proofs
  (`check_managed_ownership`, `check_override_history`, `check_hand_made_objects`) and
  `makemigrations --check`.
- Live Forward: the integration suite passes or skips for data on three lab networks, and a full
  sync into a disposable Nautobot passes, including delete governance and override history.
- Not proven: retry on a real `SYSTEM_ERROR` (mocks only), and the live NQE-diff proof with a real
  before and after pair on this SDK (no lab network currently has two processed snapshots).
